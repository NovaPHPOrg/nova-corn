# nova-corn

在「系统 → 定时任务 → 调度设置」选择调度方式。默认为内置调度，兼容原有部署。

- **内置调度**：网站自动启动不限时调度器，保留正常进程轮换。
- **CLI 调度**：保存设置后，以与网站相同的系统用户在服务器执行页面显示的 `php /项目目录/nova/plugin/corn/corn.php`（脚本位于本模块内，不放入 public），每 10 秒扫描一次。需要 Linux/Unix CLI PHP 的 pcntl 扩展，建议使用 systemd 或 Supervisor 守护。`--once` 只扫描一次，供外部秒级计划任务调用。
- **外部 URL 调度**：保存设置后，每 10 秒 GET 页面显示的 `/corn/api/run?token=<调度Token>` 地址。调度 Token 为 `corn.token` 独立配置（首次自动生成，可在页面重置），不使用个人 Token，无需登录；Token 无效返回 403。

只有选中的入口会运行。扫描共用项目级文件锁，重复触发返回 HTTP 409；成功返回 HTTP 200。客户端断开不会终止扫描。任务执行仍使用原有异步流程及任务级互斥，切换方式不终止已经运行的任务。

## CLI 任务注册

选中 CLI 调度时，每轮扫描前执行框架初始化，包括插件注册、应用的 `onFrameworkStart()` 钩子及 `framework.start` 事件，不执行 HTTP 路由分发。业务任务由应用启动钩子注册，插件不引用具体业务类，也不需要额外的任务注册回调配置。启动钩子失败时停止本轮扫描并以非零状态退出。
